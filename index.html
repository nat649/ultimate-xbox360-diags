[Tutorial] Retrieving Secondary Error Codes

Read this before posting asking what your RROD means.

If your console has 1, 3, and 4 flashing red lights on the Ring of Light (or a red light for slim and E) you have a hardware failure. The dashboard E-codes (like E74) also have corresponding hidden codes. Don't just guess or bake your motherboard in a towel. Get the exact code.

  1. Turn the console on and wait for the red lights to flash.
  2. Press and hold the Sync button on the front.
  3. While holding Sync, press the Eject button on the DVD drive once.
  4. The flashing lights will change. Count the illuminated quadrants for that digit.
  5. Release Eject, then press it again (while still holding Sync). Repeat to read all 4 digits in sequence.

Each digit is a count of lit quadrants, so every digit is 0-3. The four digits together form the secondary code (e.g. 0102).

[Database] Complete Error Code List

Code Sub-System Common Boards Scene Diagnosis & Fix
0001 Power All Phats 12V line short. Test with a known working PSU. If it still fails, check the MOSFETs near the main power connector on the motherboard for a short to ground.
0002 Power/Eth Xenon, Zephyr CPU Vcore short. Usually a blown CPU MOSFET. Can also be a shorted Ethernet transformer chip on the back of the board.
0003 Power/GPU All GPU Vcore short. A power supply phase feeding the GPU is dead (bad MOSFET or capacitor) or the silicon inside the GPU is internally shorted.
0010 SB Xenon, Zephyr Southbridge is overheating or has cold joints. Check thermal connection. If fine, the chip may need a reflow/reball.
0011 CPU Phats CPU Overheating. Heatsink is unseated, thermal paste is dust, or fans have failed. Easiest RROD to fix.
0012 GPU Phats GPU Overheating. Check GPU heatsink seating. Ensure the x-clamps haven't popped off or lost tension.
0013 RAM Phats RAM Overheating. Often caused by terrible "penny tricks" or bolt-mods that bent the board and stressed the RAM thermal pads.
0020 GPU Boot All Phats GPU failed to respond to POST. Usually signifies a dying GPU die (bump failure) requiring chip replacement.
0021 DVD / SB Xenon, Falcon DVD Drive timeout or Southbridge failure. If testing a bare board with no DVD drive connected, your Southbridge is dead.
0022 CPU / NAND Jasper, Slims Fatal CPU failure or bad NAND data. On RGH consoles, means wrong CPU key or bad PLL soldering. On retail, usually unrepairable CPU death.
0023 SB All Southbridge to CPU communication error. Failing Southbridge chip or a severed pad on the FSB.
0031 RAM All RAM short circuit. A memory chip is damaged or bridged.
0032 CPU / RAM Xenon, Zephyr CPU to RAM comms failure. Board warping likely snapped microscopic traces under the CPU.
0033 RAM Phats RAM configuration error. Solder joints under a RAM module have failed. Requires RAM reball.
0100 GPU / RAM Xenon, Zephyr Cold solder joint under RAM or GPU. Common on consoles stored in damp environments.
0101 USB / SB Corona, Trinity Short on USB ports or dead Southbridge. Inspect front/rear USB ports for bent pins. If clear, the SB chip is dead (common on Coronas).
0102 GPU Xenon, Falcon The Classic RROD. Low-TG underfill beneath the GPU chip failed, breaking solder bumps inside the chip. The towel trick is a lie. Requires a GPU replacement.
0103 GPU Zephyr, Falcon CPU to GPU comms error. Structurally identical to 0102; the GPU die underfill has failed.
0110 RAM All Memory error. The GPU cannot communicate with the RAM. Dead RAM chip or cracked solder pad under a module.
0203 Thermal Phats System control thermal failure. Tied to cracked joints under the GPU from severe board warping.
1001 DVD All DVD Drive receiving improper voltage, or firmware on the PCB is bricked.
1003 HDD All Hard Drive short. Remove HDD and boot. If it works, the HDD enclosure or drive is fried.
1010 HDD All Secondary for E68. eFUSE mismatch or HDD error. Pull the hard drive.
1013 Dashboard All Corrupt dashboard update. Console failed halfway through flashing. Put the dashboard update on a FAT32 USB and try booting.
1022 HANA / GPU Zephyr, Falcon Secondary for E74. Faulty AV cable (pulling on port), dead HANA chip, or broken traces between GPU and HANA. Usually a dying GPU.
1033 CPU Jasper, Trinity Fatal CPU initialization failure. Dead CPU. Unrepairable without a donor chip and matching NAND dump.
E64 / E65 DVD FW All DVD Drive Firmware error. Dashboard detects drive, but firmware OSKV doesn't match (usually a bad flashed firmware attempt).
E66 DVD Model All DVD Drive spoofing failed. Dashboard expects a Lite-On but detects a BenQ (or similar mismatch).
E68 HDD All Hard Drive error. Secondary code 1010. Remove HDD.
E71 / E79 NAND All Dashboard corruption. Hold sync while booting to clear cache. If persistent, internal NAND blocks might be failing. Or a stray default.xex at the root of your USB is being picked up (shows E71 on screen).
E73 HANA / Eth Zephyr, Falcon Ethernet port or HANA chip hardware failure. Inspect ethernet pins. Otherwise, HANA needs reflow/replacement.
E74 GPU Falcon Secondary code 1022. Breakdown of comms between GPU and HANA chip. Almost always a dying GPU requiring replacement.
No codes match that filter.

[Info] Xbox 360 Motherboard Revisions

Xenon 2005 (Launch)

  • Models: Core / Premium (No HDMI)
  • Process: 90nm CPU / 90nm GPU
  • PSU: 203W (16.5A)
The launch board. Notorious for a massive failure rate. Plagued by 0102/0110 errors caused by poor low-TG underfill on the GPU BGA failing under thermal stress. Avoid buying these.

Zephyr 2007

  • Models: Elite / Premium (Added HDMI)
  • Process: 90nm CPU / 90nm GPU
  • PSU: 203W (16.5A)
Added the HDMI port and the HANA scaler chip. Unfortunately, it uses the exact same flawed 90nm GPU design as Xenon. Extremely prone to E74 and 0102.

Early Falcon Late 2007

  • Models: Arcade / Pro / Elite
  • Process: 65nm CPU / 90nm GPU
  • PSU: 175W (14.2A)
Introduced a cooler 65nm CPU. However, it kept the old 90nm GPU. Because of the HANA chip and board layout, E74 (connection break between GPU and HANA) spiked massively here.

Late Falcon (v2) Mid 2008 (The Fix)

  • Models: Late Pro / Arcade
  • Process: 65nm CPU / 80nm GPU (Rhea)
  • PSU: 175W (14.2A)
A stealth revision by Microsoft. They swapped the GPU to an 80nm "Rhea" chip with high-TG underfill. If you have a Falcon manufactured in mid-to-late 2008, it is highly resilient to RROD. A solid board.

Opus 2008

  • Models: Warranty Replacements Only
  • Process: 65nm CPU / 80nm GPU
  • PSU: 175W (14.2A) - No HDMI
A Frankenstein board. This is a Falcon architecture reshaped to fit inside a broken Xenon case (which lacks an HDMI cutout). Used solely for Microsoft repair center returns.

Jasper Late 2008

  • Models: Arcade / Pro / Elite
  • Process: 65nm CPU / 65nm GPU
  • PSU: 150W (12.1A)
The true fix. Shrunk the GPU to 65nm, finally eliminating the massive heat and underfill issues. Arcade units had 16MB/256MB/512MB internal memory built onto the board.

Tonasket (Kronos) Late 2009

  • Models: Final Phat Runs (Super Elite)
  • Process: 65nm CPU / 65nm GPU (65nm eDRAM)
  • PSU: 150W (12.1A)
Often called "Jasper v2". Reduced the physical size of the eDRAM on the GPU. Widely considered by the modding scene to be the most bulletproof Xbox 360 phat motherboard ever made.

Trinity 2010

  • Models: Xbox 360 S (Glossy)
  • Process: 45nm CGPU (Combined)
  • PSU: 135W (10.83A)
First Slim board. Combined the CPU and GPU into one chip (CGPU). Kept the HANA chip. Very reliable. When it fails, it usually throws a "Red Dot of Death" (0101).

Corona (V1 - V6) 2011 - 2013

  • Models: Xbox 360 S / Xbox 360 E
  • Process: 45nm CGPU
  • PSU: 120W / 115W (9.6A)
Removed the HANA chip and integrated it into the Southbridge. Introduced 4GB eMMC NANDs. Southbridge failures and dead 4GB NANDs are the most common faults here.

Winchester 2014

  • Models: Late Xbox 360 E
  • Process: 45nm CGPU (No IHS)
  • PSU: 115W (9.6A)
The final revision. Microsoft removed the metal Integrated Heat Spreader (IHS) from the CGPU. Extremely reliable hardware-wise.

[Info] Every Xbox 360 Model

Three console generations — the original "Phat" (2005), the Xbox 360 S / "Slim" (2010), and the Xbox 360 E (2013) — each sold in several storage/bundle configurations. Region-exclusive re-boxes are noted where they matter.

SKU Years Storage Finish Notes
Core 2005 - 2007 None (memory unit only) Matte white Bare entry model: no HDD, composite cable, wired controller. Discontinued for the Arcade.
Pro / Premium 2005 - 2009 20 / 60 GB HDD Matte white The "standard" launch console: detachable HDD, wireless controller, component HD cable, headset.

Elite (250 GB) / bundles 2010 250 GB HDD Matte black Final Phat retail configuration, sold alongside the newly launched Slim before being retired.
