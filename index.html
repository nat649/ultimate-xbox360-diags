Retrieving Secondary Error Codes

When your console displays the Red Ring of Death (RROD) (1, 3, or 4 flashing red lights), a hidden 4-digit secondary error code pinpoints the exact hardware failure. The dashboard E-codes (like E74) also have matching secondary codes.

  1. Turn the Xbox 360 on and wait for the front ring to flash red.
  2. Press and hold the Sync button (used for controllers).
  3. While holding Sync, press the Eject button on the DVD drive once.
  4. The lights will change pattern. Count the flashing quadrants.
  5. Release Eject, press it again (still holding Sync). Do this 4 times total to reveal the 4 digits.
●●●● 4 Lights = 0
●○○○ 1 Light = 1
●●○○ 2 Lights = 2
●●●○ 3 Lights = 3

Motherboard Deep Dive

Xenon 2005

  • Models Core / Premium (No HDMI)
  • CPU / GPU 90nm / 90nm (Elston)
  • Power Supply 203W (16.5A)
  • Analysis The launch board. Plagued by 0102/0110 GPU BGA failures due to low-TG underfill combined with extreme thermal cycles. High failure rate.

Zephyr 2007

  • Models Elite / Premium (HDMI)
  • CPU / GPU 90nm / 90nm
  • Power Supply 203W (16.5A)
  • Analysis Added HDMI and the HANA scaler chip. Inherited the exact same flawed 90nm GPU design. Highly prone to E74 and 0102.

Early Falcon Late 2007

  • Models Arcade / Pro (60GB) / Elite
  • CPU / GPU 65nm / 90nm
  • Power Supply 175W (14.2A)
  • Analysis Introduced a cooler 65nm CPU, but kept the old 90nm GPU packaging. E74 (GPU-to-HANA connection break) spiked massively on these early boards.

Late Falcon (v2) Mid 2008

  • Models Late Pro / Arcade Bundles
  • CPU / GPU 65nm / 80nm (Rhea)
  • Power Supply 175W (14.2A)
  • Analysis A crucial mid-generation stealth fix. Microsoft quietly swapped to the high-TG underfill "Rhea" GPU. If your Falcon has a 2008 manufacture date, it is drastically more reliable and highly resilient against RROD.

Opus 2008

  • Models Microsoft Warranty Repairs Only
  • CPU / GPU 65nm / 80nm
  • Power Supply 175W (14.2A) - No HDMI
  • Analysis A Falcon architecture shaped to fit inside broken Xenon chassis (lacking an HDMI cutout) to fulfill repair center warranties.

Jasper Late 2008

  • Models Arcade / Pro / Elite
  • CPU / GPU 65nm / 65nm
  • Power Supply 150W (12.1A)
  • Analysis The true cure. Shrunk the GPU to 65nm, effectively solving the heat and underfill RROD issues. 16MB/256MB/512MB onboard memory variants for Arcade units.

Tonasket / Kronos Late 2009

  • Models Final Phat Runs (Super Elite)
  • CPU / GPU 65nm / 65nm (with 65nm eDRAM)
  • Power Supply 150W (12.1A)
  • Analysis Often called Jasper v2. Reduced eDRAM size, altered GPU layout. Widely regarded by the community as the most indestructible Xbox 360 motherboard ever manufactured.

Trinity 2010

  • Models Xbox 360 S (Slim) - Glossy
  • CPU / GPU 45nm CGPU (Combined)
  • Power Supply 135W (10.83A)
  • Analysis First Slim. Unified CPU/GPU die. Contains HANA chip. Excellent reliability. Failures usually result in the "Red Dot of Death" (0101).

Corona (V1-V6) 2011-2013

  • Models Xbox 360 S / Xbox 360 E
  • CPU / GPU 45nm CGPU
  • Power Supply 120W / 115W (9.6A)
  • Analysis Removed the HANA chip (integrated into Southbridge). Introduced 4GB eMMC NANDs. Southbridge failure is the most common issue here.

Winchester 2014

  • Models Late Xbox 360 E (Stingray)
  • CPU / GPU 45nm CGPU (No IHS)
  • Power Supply 115W (9.6A)
  • Analysis Final board. Missing the Integrated Heat Spreader (IHS). Completely patched against RGH/Modding. Tank-like reliability.

Comprehensive Error Database

⌕
Error Code Sub-System Primary Affected Boards Technical Diagnosis & Resolution
0001 Power PSU All Phats Short on the 12V line. Verify external power supply works first. If PSU is good, check the MOSFETs near the main power connector for a short to ground.
0002 Power Ethernet Xenon, Zephyr CPU Vcore short or Network Interface short. Often a blown CPU MOSFET, or occasionally a shorted Ethernet transformer chip on the rear of the board.
0003 Power GPU All GPU Vcore short. A power supply phase feeding the GPU has failed (bad MOSFET/capacitor) or the silicon inside the GPU is internally shorted.
0010 Thermal SB Xenon, Zephyr Southbridge overheating. Check thermal paste and mounting on the Southbridge. Alternatively, indicates severed solder joints beneath the SB chip.
0011 Thermal CPU Xenon, Zephyr, Falcon CPU Overheating. The heatsink is unseated, thermal paste is fully dry, or fans have completely failed. Usually an easy physical fix.
0012 Thermal GPU Xenon, Zephyr, Falcon GPU Overheating. Check GPU heatsink seating. Ensure the x-clamps haven't lost tension.
0013 Thermal RAM All Phats RAM Overheating. Most commonly caused by the "penny trick" or bolt-mods that over-torqued the board, bending it and stressing the RAM thermal pads.
0020 Boot GPU All Phats GPU failed to respond during POST. Usually signifies a dying GPU die (bump failure) requiring replacement, or cold joints under the GPU.
0021 Boot SB Xenon, Falcon DVD Drive timeout or Southbridge failure. If testing without a DVD drive connected and you get this, the Southbridge is dead or has broken joints.
0022 CPU NAND Jasper, Slims CPU failure, broken PLL lines, or bad NAND data. On RGH consoles, this usually means an incorrect CPU key or bad soldering. On retails, fatal CPU failure.
0023 Boot SB All Southbridge to CPU connection error. Usually points to a failing Southbridge or a lifted pad along the front-side bus.
0031 RAM All RAM short circuit. A memory chip is physically damaged, bridged, or has detached from the motherboard via a cracked solder joint.
0032 RAM CPU Xenon, Zephyr CPU to RAM communication failure. Can be a bad CPU, but often related to microscopic board warping snapping traces under the CPU.
0033 RAM All Phats RAM configuration error. Solder joints under one of the RAM modules have failed. Reflow/Reball of the memory chips required.
0100 GPU RAM Xenon, Zephyr Cold solder joint under a RAM chip or the GPU itself. Highly common when consoles underwent extreme thermal cycling in damp environments.
0101 USB SB Corona, Trinity Bridged USB ports or dead Southbridge. Inspect physical USB ports for bent pins touching the shield. If clear, Southbridge has failed (extremely common on Corona).
0102 GPU BGA Xenon, Early Falcon The Classic RROD. Low-TG underfill beneath the GPU chip failed, breaking solder bumps between the silicon die and the green substrate. Requires permanent GPU replacement with a fixed revision.
0103 GPU CPU Zephyr, Falcon CPU to GPU communication error. Structurally identical diagnosis to 0102; the GPU die underfill has failed.
0104 GPU Unknown All Phats Undocumented specific failure, but heavily tied to the GPU power phasing or cold joints on the GPU core voltage regulators.
0110 RAM All Memory error. The GPU cannot communicate with the RAM. Either a dead RAM chip or a damaged solder pad under a RAM module. Often fixable with a RAM reball.
0203 Thermal Phats System control thermal failure. Generally points back to cracked solder joints underneath the GPU caused by severe board warping.
1001 DVD Drive All DVD Drive error. The drive is receiving improper voltage, or the firmware on the DVD PCB is catastrophically corrupted.
1003 Storage HDD All Hard Drive short. Remove the hard drive. If the console boots normally, the HDD enclosure, connector, or internal drive is dead.
1010 Storage All Matches E68. eFUSE mismatch or Hard drive error. Remove the HDD and try booting.
1013 Dashboard All Corrupt dashboard update. Console failed halfway through a system update. Often recoverable by putting the update on a USB drive and booting.
1020 Network All Ethernet port or networking subsystem failure.
1021 Network SB Phats Southbridge failure relating to the network interface. Component failure near the ethernet PHY chip.
1022 AV HANA Zephyr, Falcon Matches E74. The AV cable is faulty (common with heavy Component cables pulling on the port), the HANA scaler chip has failed, or the GPU-to-HANA traces broke.
1023 DVD Drive All DVD drive is not connected, or the SATA data cable connecting the DVD drive to the Southbridge is faulty/damaged.
1033 CPU Jasper, Trinity Fatal CPU failure. The CPU cannot initialize during the very first stages of POST. Unrepairable without a donor CPU and matching NAND.
E64 / E65 DVD Drive All DVD Drive Firmware error. The dashboard detects a drive, but the firmware version doesn't match the expected OSKV (often caused by bad flashed firmware).
E66 DVD Drive All DVD Drive model mismatch. The dashboard expects one drive brand (e.g., Lite-On) but detects another (e.g., BenQ) and the firmware is strictly checking.
E67 / E68 Storage All Hard Drive timeout or read/write error. Remove the hard drive. If the console boots, replace the hard drive.
E71 / E79 Dashboard NAND All Dashboard update error or corrupted file system. Try clearing the system cache (hold sync button while booting). Can also indicate failing NAND flash blocks.
E73 Network HANA Zephyr, Falcon Hardware failure on the Ethernet port or HANA chip. Check ethernet pins. If clear, the HANA chip needs reflowing or replacing.
E74 GPU HANA Falcon Secondary code 1022. Breakdown of communication between GPU and HANA chip. Almost always a dying GPU die requiring replacement.
